# 기본 앱 계약

사용자의 교육 계약을 구체화한 starter 기준이며, 실습 두 ticket의 완료를 뜻하지 않는다.

| ID | 독립적인 기대 결과 |
| --- | --- |
| BASE-01 | minsu/jiyun과 공개 교육 비밀번호로 로그인, 잘못된 비밀번호 거절, 로그아웃 후 API 401. |
| BASE-02 | GET /api/todos는 본인 항목만 id 내림차순 배열로 반환하고 빈 목록은 []이다. |
| BASE-03 | POST는 제목의 양끝 공백을 제거하여 201 {id,title,completed:false}; 소유자는 세션으로만 결정한다. |
| BASE-04 | PUT /api/todos/{id}는 제목과 완료 여부를 명시하여 200; 완료와 미완료 전환 모두 가능하다. |
| BASE-05 | DELETE는 본인 항목만 204로 삭제한다. 다른 사용자 ID와 없는 ID는 PUT/DELETE 모두 동일한 404이며 데이터는 변하지 않는다. |
| BASE-06 | 제목 null/빈문자/공백/121자는 400; 1자/120자는 허용. completed 누락/null은 400. 잘못된 JSON/ID/알 수 없는 필드도 400. |
| BASE-07 | API 오류는 {code,message}; 인증 없음 401, CSRF 없음 403. UI는 오류를 한국어로 보여준다. |
| BASE-08 | 한국어 목록, 명시적으로 여는 행 편집, 완료/되돌리기, 제목을 표시하는 삭제 확인, 빈 상태, 키보드 이동과 저장이 동작한다. |
| BASE-09 | 재기동해도 파일 DB 데이터가 유지되고 최초 시드는 한 번만 들어간다. |

기본 API는 status 필터를 구현하지 않는다.
조회 컨트롤러의 작은 repository 호출은 ticket 2의 공개된 교육 시작점이며 보안 결함이 아니다.
