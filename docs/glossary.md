# 용어

| 용어 | 의미 |
| --- | --- |
| PRD | 구현 전에 확정할 문제, 범위, 보존 동작, 검증 계약 |
| AC-ID | PRD 각 완료 조건의 고유 ID |
| 가이드 | 반복되는 도메인 규칙의 단일 원본 |
| 지역 CLAUDE.md | 가까운 맥락과 해당 가이드의 위치 안내 |
| 활성 task | `.artifacts/active-task.json`에 명시적으로 선택한 작업 |
| fingerprint | 검증한 입력 파일 경로와 내용의 해시 |
| stale | 검증 이후 입력이 바뀌어 결과를 재사용할 수 없는 상태 |
| verifier | 구현자의 설명과 분리해 직접 검증하는 새 컨텍스트 에이전트 |
| BLOCKED | 검증 불가 또는 미완료, PASS와 구분되는 종료 |
| 하네스 | 지침·스킬·에이전트·훅·도구·증거 규칙을 묶은 작업 환경 |
