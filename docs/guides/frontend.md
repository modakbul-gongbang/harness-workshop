# G-FRONTEND: 화면

- 한국어 읽기 목록이 기본이며 수정 버튼으로 해당 행의 폼만 연다.
- `src/app/globals.css`의 색/간격/반경/타이포 토큰을 사용한다. 새로운 카드 그리드를 만들지 않는다.
- 제목은 React 텍스트 노드로 렌더하며 dangerouslySetInnerHTML을 사용하지 않는다.
- 로딩/빈 목록/실패와 재시도/버튼 pending을 표현하고 실제 데이터에서 개수를 계산한다.
- 모든 입력에 label, 행 액션에 제목 포함 접근성 이름, 키보드 focus 표시를 둔다.
- Enter 저장, Escape 편집 취소, 액션 뒤 합리적인 focus 복귀를 보존한다.
- 삭제는 제목과 되돌릴 수 없음을 확인하고 기본 focus는 유지하기다.
- 390px 모바일과 데스크톱에서 한국어/120자/줄바꿈을 실제 브라우저로 확인한다.
- 변경 요청에 CSRF 토큰을 보내고 실패를 한국어로 표시한다.

## 상태와 복구를 검토하는 순서

| 상태 | 사용자가 확인할 결과 |
| --- | --- |
| 첫 조회 중 | 로딩 표시와 사용할 수 없는 액션 구분 |
| 조회 성공·0건 | 실패 메시지와 구별되는 빈 목록 |
| 조회 실패 | 한국어 오류와 명시적인 목록 재시도 |
| 변경 전송 중 | 중복 전송을 막는 pending 표시 |
| 저장 성공·재조회 실패 | 저장 성공 여부를 보존하고 목록 조회만 재시도 |
| 변경 실패 | 오류 표시와 다시 사용할 수 있는 조작 |
| 인증 만료 | 기존 로그인 이동 흐름 |

화면 변경은 핵심 동작을 마우스와 키보드로 실행하고 수정·취소·삭제 뒤 focus 위치를 확인한다.
모바일에서는 긴 제목이 버튼·행·dialog 밖으로 넘치지 않는지 확인한다.
수량·완료 개수는 서버에서 읽은 현재 데이터에 근거하며 로딩·오류 때 이전 값을 새 결과처럼 보이지 않는다.
브라우저 검증 환경과 증거는 [검증 가이드](testing.md)를 따른다.
