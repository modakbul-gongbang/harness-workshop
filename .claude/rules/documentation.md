# 문서와 하네스 설명 규칙

- 긴 Markdown은 문장마다 물리적인 줄을 나누고 목록·표·코드 블록 구조를 유지한다.
- 루트 CLAUDE.md에는 공통 명령과 탐색 지도를, 하위 CLAUDE.md에는 해당 모듈의 수정 경계를 둔다.
  교차 경로 컨벤션은 Rules, 상세 판정은 docs 가이드에 둔다.
- 같은 규칙의 전체 사본을 여러 문서에 만들지 않는다.
  요약 뒤 기준 문서의 상대 링크나 프로젝트 루트 기준 경로를 붙인다.
- 명령·경로·현재 구현과 실습 후 목표를 구분하고 실제 파일로 확인한다.
  자동 생성 표시가 있는 블록은 수동으로 고치지 않는다.
- PRD의 AC-ID·G-ID·검증 범위 표 형식은 `scripts/task.py`가 읽는 계약이다.
  바꾸면 파서·템플릿·fixture와 관련 가이드를 함께 검토한다.
- 실행한 검사와 실행하지 않은 검사를 구분한다.
  Rules의 문장 지침을 hook·lint가 모두 강제한다고 설명하지 않는다.
